## 一、角色定义

| 角色代码 | 角色名称 | 说明 |
|----------|----------|------|
| ADMIN | 管理员 | 系统管理者，拥有最高权限 |
| DISPATCHER | 调度员 | 负责订单调度和车辆分配 |
| DRIVER | 司机 | 执行运输任务 |
| CUSTOMER | 客户 | 下单查询 |

**重要**：后端 login 接口返回的是 `role: "ADMIN"` 代码格式，前端统一使用角色代码进行权限判断。

## 七、前端权限实现方案

### 7.1 权限标识符设计

采用 `模块:操作` 格式：

| 权限标识 | 说明 |
|----------|------|
| user:view | 查看用户列表 |
| user:add | 新增用户 |
| user:edit | 编辑用户 |
| user:delete | 删除用户 |
| user:reset-password | 重置密码 |
| user:status | 启用/禁用用户 |
| vehicle:view | 查看车辆列表 |
| vehicle:add | 新增车辆 |
| vehicle:edit | 编辑车辆 |
| vehicle:delete | 删除车辆 |
| vehicle:idle | 查看空闲车辆 |
| order:view | 查看订单列表 |
| order:add | 创建订单 |
| order:edit | 编辑订单 |
| order:cancel | 取消订单 |
| order:track | 查看订单轨迹 |
| dispatch:view | 查看调度列表 |
| dispatch:add | 创建调度 |
| dispatch:edit | 编辑调度 |
| dispatch:delete | 删除调度 |
| dispatch:status | 更新调度状态 |
| dispatch:sign | 签收 |
| dispatch:pending | 查看待调度订单 |
| location:report | 上报位置 |
| location:query | 查询轨迹 |
| settings:view | 查看设置 |
| settings:edit | 编辑个人信息 |
| settings:password | 修改密码 |

### 7.2 用户信息结构

```typescript
interface UserInfo {
  id: number;
  username: string;
  realName: string;
  phone: string;
  role: string;          // 角色代码：ADMIN / DISPATCHER / DRIVER / CUSTOMER
  roleId: number;
  roleName: string;      // 角色名称：管理员 / 调度员 / 司机 / 客户
  status: number;        // 0禁用 1启用
}
```

**登录接口返回示例**：

```json
{
  "code": 200,
  "data": {
    "token": "xxx",
    "user": {
      "id": 1,
      "username": "admin",
      "realName": "系统管理员",
      "phone": "13800138000",
      "role": "ADMIN",
      "roleId": 1,
      "roleName": "管理员",
      "status": 1
    }
  }
}
```

### 7.3 路由 Meta 配置

```typescript
{
  path: '/dashboard/user',
  component: () => import('@/views/user/index.vue'),
  meta: {
    requiresAuth: true,
    permissions: ['user:view'],
    locale: 'menu.user',
    icon: 'icon-user',
  }
}
```

### 7.4 菜单数据结构

```typescript
interface MenuItem {
  key: string;
  title: string;
  icon?: string;
  path?: string;
  permissions: string[];
  children?: MenuItem[];
}
```

### 7.5 按钮权限使用

```vue
<!-- 方式1: v-permission 指令（自动隐藏） -->
<a-button v-permission="'order:add'">创建订单</a-button>

<!-- 方式2: 编程式检查 -->
<a-button v-if="hasPermission('order:cancel')">取消订单</a-button>

<!-- 方式3: 组合式函数 -->
<a-button v-if="hasAnyPermission(['dispatch:edit', 'dispatch:status'])">
  调度操作
</a-button>
```

## 八、状态相关权限说明

以下权限与数据状态相关，前端展示时需注意：

| 场景 | 条件 | 可执行角色 |
|------|------|-----------|
| 编辑订单 | 订单状态 = PENDING | ADMIN, DISPATCHER |
| 取消订单 | 订单状态 = PENDING | ADMIN, DISPATCHER, CUSTOMER（仅自己的） |
| 取消订单 | 订单状态 = DISPATCHED/IN_TRANSIT | ADMIN, DISPATCHER（提示联系调度/司机） |
| 更新调度状态 | 调度状态流转 | ADMIN, DISPATCHER, DRIVER（仅自己的） |
| 签收 | 调度状态 = ARRIVED | ADMIN, DISPATCHER |
| 上报位置 | 调度状态 = ASSIGNED / IN_TRANSIT | DRIVER |
