## 2. 认证模块

### 2.1 登录

**接口路径：** `POST /api/auth/login`

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| username | string | 是 | 用户名 | admin |
| password | string | 是 | 密码 | 123456 |

**请求示例：**
```json
{
  "username": "admin",
  "password": "123456"
}
```

**响应参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码 |
| message | string | 消息 |
| data.token | string | JWT Token |
| data.expireTime | long | 过期时间戳 |
| data.user.id | long | 用户ID |
| data.user.username | string | 用户名 |
| data.user.realName | string | 真实姓名 |
| data.user.role | string | 角色代码 |
| data.user.roleId | long | 角色ID |

**响应示例：**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expireTime": 1713868800000,
    "user": {
      "id": 1,
      "username": "admin",
      "realName": "系统管理员",
      "role": "ADMIN",
      "roleId": 1
    }
  }
}
```

### 3.3 编辑用户

**接口路径：** `PUT /api/users/{id}`

**权限：**
- ADMIN：可编辑所有用户的所有字段
- DISPATCHER：可编辑 DRIVER 角色的 phone, realName, password
- DRIVER/CUSTOMER：只能编辑自己的 phone, realName

**路径参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | long | 是 | 用户ID |

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 | 可编辑角色 |
|--------|------|------|------|------------|
| realName | string | 否 | 真实姓名 | ALL |
| phone | string | 否 | 手机号 | ALL |
| password | string | 否 | 密码 | ADMIN, DISPATCHER(仅DRIVER) |
| roleId | long | 否 | 角色ID | ADMIN |
| status | int | 否 | 状态 | ADMIN |

**请求示例（ADMIN）：**
```json
{
  "realName": "张三（修改）",
  "phone": "13800138001",
  "status": 1
}
```

**请求示例（DISPATCHER修改DRIVER）：**
```json
{
  "realName": "张三（修改）",
  "phone": "13800138001",
  "password": "654321"
}
```

**响应示例：**
```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

**错误响应示例（无权修改）：**
```json
{
  "code": 403,
  "message": "无权修改该用户",
  "data": null
}
```

## 5. 订单模块

**接口路径：** `GET /orders`

**权限：**
- ADMIN, DISPATCHER：查看所有订单
- DRIVER：查看自己相关的订单（通过调度关联）
- CUSTOMER：查看自己的订单

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| page | int | 否 | 页码，默认1 | 1 |
| size | int | 否 | 每页条数，默认10 | 10 |
| orderNo | string | 否 | 订单号 | ORD20260423001 |
| status | string | 否 | 状态 | PENDING |
| startDate | string | 否 | 开始日期 | 2026-04-01 |
| endDate | string | 否 | 结束日期 | 2026-04-30 |

**订单状态说明：**

| 状态 | 说明 |
|------|------|
| PENDING | 待调度 |
| DISPATCHED | 已调度 |

| ARRIVED | 已到达 |
| SIGNED | 已签收 |
| CANCELLED | 已取消 |

**响应参数：**

| 参数名 | 类型 | 说明 |

| data.records | array | 订单列表 |

| data.records[].shipperPhone | string | 发货人电话 |
| data.records[].shipperAddress | string | 发货地址 |
| data.records[].receiverName | string | 收货人 |

| data.records[].dispatchId | long | 调度单ID |
