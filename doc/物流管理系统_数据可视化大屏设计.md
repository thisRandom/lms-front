# 物流管理系统 - 数据可视化大屏设计

> 设计日期：2026-05-03

## 一、设计目标

为物流管理系统（LMS）的四个角色（管理员、调度员、司机、客户）设计专属的数据可视化大屏，帮助各类用户快速了解关键业务指标，提升决策效率。

---

## 二、角色大盘设计总览

| 角色 | 核心场景 | 关键指标 |
|------|---------|---------|
| ADMIN | 全局运营概览 | 订单/调度/车辆/用户全局统计 |
| DISPATCHER | 实时调度监控 | 待调度订单、车辆实时位置、调度效率 |
| DRIVER | 我的任务与收入 | 当前任务、收入统计、车辆状态 |
| CUSTOMER | 我的订单追踪 | 订单状态、实时位置、运费统计 |

---

## 三、各角色详细设计

### 3.1 ADMIN - 管理员大屏

#### 3.1.1 页面布局（6个核心模块）

```
┌─────────────────────────────────────────────────────────────────┐
│                        运营概览数字卡片                          │
│  [今日新增订单] [今日进行中] [今日已完成] [待调度订单] [空闲车辆] [在线司机] │
├──────────────────────────────────┬──────────────────────────────┤
│         订单状态分布（饼图）       │        近7日订单趋势（折线图）    │
│                                  │                               │
├──────────────────────────────────┼──────────────────────────────┤
│         车辆类型分布（饼图）       │       调度状态分布（柱状图）      │
│                                  │                               │
├──────────────────────────────────┼──────────────────────────────┤
│         用户角色分布（饼图）       │       各线路调度量（柱状图）      │
└──────────────────────────────────┴──────────────────────────────┘
```

#### 3.1.2 需要展示的指标

| 类别 | 指标名称 | 说明 |
|------|---------|------|
| 运营概览 | 今日新增订单数 | 当日创建订单数量 |
| 运营概览 | 今日新增订单重量 | 当日订单货物总重量（吨） |
| 运营概览 | 今日进行中调度数 | 状态为 IN_TRANSIT 的调度数 |
| 运营概览 | 今日已完成签收数 | 状态为 SIGNED 的调度数 |
| 运营概览 | 待调度订单数 | 尚未分配车辆的订单数 |
| 运营概览 | 空闲车辆数 | 状态为 IDLE 的车辆数 |
| 运力分析 | 在线司机数 | 当前有活跃调度的司机数 |
| 运力分析 | 车辆总数 | 系统注册车辆总数 |
| 运力分析 | 各类型车辆占比 | 按 vehicleType 统计 |
| 订单分析 | 订单状态分布 | 按 status 统计各状态订单数 |
| 订单分析 | 订单重量/体积统计 | 总重量、总体积、平均单票重量 |
| 订单分析 | 近7日订单趋势 | 每日订单数量变化 |
| 调度分析 | 调度状态分布 | 各状态调度数量 |
| 调度分析 | 平均运输时长 | 从 ASSIGNED 到 SIGNED 的平均时长（分钟） |
| 调度分析 | 各线路调度量 | 按出发地-目的地统计 |
| 用户分析 | 用户角色分布 | 各角色用户数量 |
| 用户分析 | 用户增长趋势 | 近7日新增用户数 |

## 五、可视化组件选型建议

| 图表类型 | 适用场景 | 推荐组件库 |
|---------|---------|----------|
| 数字卡片 | 核心指标展示（订单数、车辆数等） | Arco Design Statistic |
| 折线图 | 趋势变化（近7日订单、里程趋势） | ECharts line |
| 柱状图 | 对比分析（各线路调度量、类型分布） | ECharts bar |
| 饼图 | 占比分析（订单状态、车辆类型、用户角色） | ECharts pie |
| 地图 | 位置展示（车辆实时位置、运输轨迹） | ECharts map / 高德地图 |
| 表格 | 列表数据（待处理订单、空闲车辆） | Arco Design Table |

## 八、技术注意事项

1. **数据刷新策略**：大屏数据建议每 30 秒自动刷新一次，地图位置每 10 秒刷新
2. **权限控制**：大屏页面需根据角色显示对应内容，可在路由守卫中处理
3. **地图集成**：车辆位置和轨迹展示需要接入高德地图或百度地图 SDK
4. **图表性能**：数据量较大时注意分页或采样，避免渲染卡顿
5. **响应式设计**：大屏页面需适配不同屏幕尺寸，建议使用 rem 或 vw 单位
